## Key Questions Judges Might Ask (and How to Answer)

**Q1: Did you use AI-generated music or synthesizer presets?**  
*Answer:* No. Every note is synthesized live in the browser using the Web Audio API based on exact mathematical equations mapping NASA numerical data directly to sound frequencies.

**Q2: What is the reference baseline?**  
*Answer:* We use NASA GISTEMP's standard 1951–1980 global climate reference period as our 0.00°C anomaly baseline, anchored at 400 Hz.

**Q3: How accessible is the interface?**  
*Answer:* The website features high-contrast visible focus rings, full keyboard shortcuts (Space, Arrow keys, Home, End, Mute), an Audio Legend explaining every acoustic mapping, and ARIA live regions for assistive technology.
