# EARTHBEAT – Hear Our Planet

**NASA Space Apps Challenge 2026**

**Team:** Stellar Mind X  
**Challenge:** The Earth Information Jukebox  
**Location:** Harohalli, Karnataka, India

## Live Website

[Open EARTHBEAT](PASTE_YOUR_NETLIFY_LINK_HERE)

## Project Features

- Real-time temperature data extraction using NASA POWER API.
- Web Audio API-based sonification engine.
- Interactive frontend using HTML, CSS and JavaScript.
- Converts Earth data into audible experiences.

## Project Goal

To make Earth science more engaging and accessible by transforming NASA Earth data into sound.
